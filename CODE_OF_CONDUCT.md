# Code of Conduct

## Our pledge

We want this project to be a welcoming, respectful and constructive space for everyone.

## Expected behavior

- Be respectful and professional.
- Assume good intent and discuss ideas, not people.
- Give actionable and constructive feedback.
- Respect different experience levels and backgrounds.
- Keep discussions focused on improving the project.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, sexualized behavior, trolling and intentionally disruptive behavior are not welcome.

## Enforcement

Project maintainers may remove comments, close issues or reject contributions that violate this Code of Conduct.

For serious or sensitive concerns, use the private reporting process described in [SECURITY.md](SECURITY.md).
