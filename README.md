# Personal Resume Template

A modern, responsive and customizable Persian resume & portfolio template built with **Vite**, **Tailwind CSS** and **Vanilla JavaScript**.

> Fork it, replace the sample content, and make it your own resume website.

## ✨ Features

- RTL / Persian-first layout
- Responsive design for desktop, tablet and mobile
- Dark / light theme
- Smooth reveal animations
- Typewriter effect
- Customizable profile, skills, experience and projects
- Downloadable resume PDF
- No backend required
- Vite production build
- Ready for GitHub Pages

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES Modules)
- Tailwind CSS
- Vite

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/personal-resume-template.git
cd personal-resume-template
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```

### 5. Preview the production build

```bash
npm run preview
```

## 🎨 Customization

Most personal content lives in:

```text
src/data/content.js
```

Update your name, title, contact details, bio, stats, skills, experience and projects there. Replace the sample resume at `src/assets/resume.pdf`.
