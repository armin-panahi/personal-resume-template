# Security Policy

## Supported versions

Security fixes are applied to the latest version of the project.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub Issues.

Until a private security contact is configured, use GitHub's private vulnerability reporting feature when it is available for the repository.

When reporting a vulnerability, include:

- A clear description of the issue
- Steps to reproduce it
- The potential impact
- A suggested fix, if available

Please allow maintainers reasonable time to investigate before publicly disclosing a vulnerability.
